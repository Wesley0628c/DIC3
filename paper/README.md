# Food Guardian — IEEE Conference Paper Draft (Overleaf Package)

This folder contains the complete LaTeX source for the IEEE conference paper draft:
**"Food Guardian: An Inventory-Aware AI Agent for Household Food Management and Waste Reduction"**

## Files
- `main.tex`: Full IEEE 2-column conference paper manuscript.
- `references.bib`: Standard BibTeX bibliography containing citations (R1–R7, T1, S1).
- `ieee-food-guardian-overleaf.zip`: Pre-packaged zip archive for 1-click import into Overleaf.

## How to Import into Overleaf
1. Download or locate `ieee-food-guardian-overleaf.zip` (available in this directory or the workspace root).
2. Go to [Overleaf](https://www.overleaf.com/).
3. Click **New Project** $\rightarrow$ **Upload Project**.
4. Drag and drop `ieee-food-guardian-overleaf.zip`.
5. Overleaf will automatically detect `main.tex` and compile using pdfLaTeX / TeX Live.

## Syncing with GitHub
Overleaf premium / institutional accounts support direct two-way synchronization with this GitHub repository:
