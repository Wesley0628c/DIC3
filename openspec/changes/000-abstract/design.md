# Context
IEEE conference papers require a concise single-paragraph abstract (200–250 words) and indexed keywords.

# Goals / Non-Goals
## Goals
- Cover A–F: Attention Getter, But, Cure, Development, Experiments, Findings.
- Define 6 relevant IEEE keywords.

## Non-Goals
- Claiming completed physical household waste reduction.

# Decisions
- Place abstract in `paper/sections/000_abstract.tex`.
- Use standard `\begin{abstract}` and `\begin{IEEEkeywords}`.
