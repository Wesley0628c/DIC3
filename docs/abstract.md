# 專業摘要

## A. Attention Getter — 動機與引題

全球食物浪費已成為永續發展的重要挑戰。聯合國環境規劃署（UNEP）《Food Waste Index Report 2024》指出，2022 年全球共浪費約 10.5 億公噸食物，相當於可供消費食物的 19%；其中家庭端浪費約 6.31 億公噸，占總量 60%，為最主要來源。家庭食材浪費常源於庫存掌握不足、忘記使用、餐點規劃不當，以及對保存期限與食品安全資訊的誤解。美國 FDA 估計，日期標示混淆造成約 20% 的消費者食物浪費，顯示「何時該用、何時該丟」仍是家庭管理食材的關鍵難題。

## B. But — 現有問題與挑戰

現有食材管理工具多僅提供庫存紀錄、保存期限提醒或食譜推薦，功能彼此分散，缺乏完整決策流程。一般生成式 AI 食譜系統雖能依需求產生菜色，但未必確認使用者實際擁有的食材、數量與保存狀態，也可能未納入食品安全規則。當系統無法說明「為何推薦此餐點」與「為何優先使用某食材」，使用者難以信任其建議，進而降低實際採用意願。

## C. Cure — 提出的解決方案

本研究提出 **Food Guardian**，一套結合人工智慧代理人（AI Agent）、食品領域知識與資料分析的智慧食材管理系統。系統以「食品安全優先、庫存透明、庫存優先規劃、資料驅動與個人化調整」為核心，透過 AI Agent 整合庫存查詢、臨期食材排序、食譜推薦與保存風險檢查，協助家庭將現有食材轉化為可行餐點。

## D. Development — 研究方法

系統以 Python 開發，採用 Streamlit 建立使用者介面，SQLite 儲存食材、食譜與使用紀錄，並以 Pandas 進行庫存統計與浪費分析。核心架構為具 Tool Calling 能力的 LLM Agent：Agent 解析使用者需求後，呼叫資料庫取得庫存與日期資訊，計算食材優先順序，再依 JSON 食品保存知識庫與規則檢查過濾不安全或資料不足的項目，最後產出可解釋的餐點建議。

## E. Experiments — 實驗與評估

研究將建立 20–30 種常見食材、20–30 道基本食譜及 30 組測試情境，涵蓋庫存充足、食材短缺與臨期風險等狀況。實驗以未整合真實庫存的一般 LLM 食譜推薦作為 Baseline，比較 Food Guardian 在相同情境下的表現。評估指標包括食譜可行率（Recipe Feasibility Rate）、庫存匹配率（Inventory Matching Rate）與日期提醒準確率（Reminder Accuracy），並透過 Pandas 分析食材使用量、丟棄量與浪費比例。

## F. Findings — 預期成果

預期 Food Guardian 能提升餐點推薦與家庭庫存的匹配程度，優先安排臨期食材使用，並透過規則驗證降低不安全建議風險。系統將提供可解釋的推薦理由，例如「優先使用臨期食材」「資料不足故不建議使用」或「庫存不足需補充」。本研究亦將明確區分模擬結果與真實家庭成效，避免過度宣稱減廢效果；後續可透過長期使用者試驗，驗證系統對食材使用、庫存更新與實際食物浪費的影響。UNEP 報告亦強調，建立可衡量、可比較的浪費資料，是推動減量行動與追蹤 SDG 12.3 進展的基礎。
