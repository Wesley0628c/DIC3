# Food Guardian 專案摘要（約 500 字）

家庭食材浪費常與庫存掌握不足、忘記使用及餐點規劃不當有關。現有食材管理工具多著重庫存紀錄、期限提醒或食譜推薦，功能缺乏整合；一般生成式人工智慧也未必依據實際庫存與保存狀態提出建議，可能產生食材不足或不符安全規則的餐點。

本研究擬提出 Food Guardian 智慧食材管理系統，結合人工智慧代理人、食品保存知識與資料分析，以食品安全優先、庫存透明、庫存優先規劃、資料驅動及個人化調整為核心，協助家庭安排食材使用順序並規劃可行餐點。

系統規劃以 Python 開發，使用 Streamlit 建立介面、SQLite 儲存庫存與使用紀錄，並透過 Pandas 分析食材使用及浪費情形。代理人將藉由工具呼叫查詢庫存，排序臨期食材，再依 JSON 保存知識庫與規則進行風險檢查；資料不足時要求補充，並提供推薦理由，庫存異動則須經使用者確認。

評估將建立二十至三十種食材、二十至三十道食譜及三十組測試情境，涵蓋庫存充足、食材短缺與臨期風險，並與未整合真實庫存的一般語言模型推薦比較，衡量食譜可行率、庫存匹配率及日期提醒準確率。

預期產出為可解釋的食材管理原型與可重現的評估流程，提升推薦與庫存的一致性，降低不安全建議風險。本研究目前屬提案階段，尚未取得實驗結果，實際減廢成效仍需後續家庭使用試驗驗證。
