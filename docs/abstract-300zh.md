# 第二部分：Food Guardian 中文摘要（約 300 字）

家庭食材浪費常與庫存掌握不足、忘記使用及餐點規劃不當有關。生成式人工智慧雖能推薦食譜，仍需核對實際庫存、份量與保存條件。本研究提出 Food Guardian，結合語言模型代理人、庫存資料庫、食品保存規則與資料分析，協助家庭安排食材使用順序。系統以工具呼叫查詢庫存，篩選符合規則的食材並排序臨期項目，再產生餐點候選、驗證用量與提供推薦理由；資訊不足時主動追問，庫存異動須經使用者確認。研究將建立二十至三十種食材、二十至三十道食譜及三十組情境，與一般語言模型及取得相同庫存資料的模型比較，評估食譜可行率、庫存匹配率與日期提醒準確率。預期交付可解釋原型與可重現評估流程；實際減廢效果仍待家庭試驗驗證。

研究證據、來源與評估定義見[第二部分研究補強](proposal-strengthening.md)。本摘要為提案，未宣稱已取得實驗結果。
