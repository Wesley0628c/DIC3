# Food Guardian 食品智慧代理人研究提案解析

## 專題核心定位
- **四大要素**：AI Agent + Domain Knowledge + Data Analytics + Real-World Application
- **核心目標**：解決家庭食材管理中「剩餘數量不明、保存狀態模糊、使用順序混淆」三大核心問題。
- **混合架構**：LLM 負責自然語言互動與 Planner 意圖識別；SQLite 提供真實批次庫存；Python 確定性規則引擎執行換算、硬限制篩選與過期預警。
- **誠實邊界**：日期提醒不代表生化食安保證；所有減廢成效數據均為後續規劃，不虛構實驗結果。
